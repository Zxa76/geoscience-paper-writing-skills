# 沉积地质写作指南

本指南为规范性方法提醒，不代表已经从用户的 Zotero 全文中归纳出写作规律。

## 范围与论证链

适用于沉积构造、岩相、沉积旋回与地层、古环境研究。先明确盆地、剖面或井、地层单位、样品与尺度，再组织“观察事实 → 岩相及相组合 → 沉积过程 → 地层与环境解释 → 区域意义”。把实测、文献事实和作者解释分开，避免把解释重新当作独立证据。

## 证据与方法约束

- 岩相命名对应可描述的岩性、粒度、组构或构造；环境解释需多类证据支持，并讨论可竞争的解释。
- 地层对比注明年代依据、界面识别、缺失和分辨率；岩性相似或测井曲线形态接近不能独立证明等时。
- 沉积旋回注明采样间距、时间控制、趋势处理、统计背景及稳健性；检测周期后再讨论其可能驱动，不能直接断言天文成因。
- 古环境指标检查物源、粒度、成岩、风化、成熟度和归一化方式的影响；避免单一元素比值独立判定缺氧、盐度或生产力。
- 讨论协变关系时区分稀释、保存与生产作用；不能仅由 TOC 升高推出生产力增强或水体缺氧。
- 图件保留深度或高度基准、地层界线、采样位置、单位和缺测说明；跨剖面对比交代尺度差异。

写作前核对薄片、露头、岩心描述与地球化学样品能否逐一对应。证据发生冲突时，保留冲突并说明哪一尺度或过程可能造成差异。没有充分年代约束时，允许使用相对层序和层位关系表达，不补造绝对年龄或沉积速率。

## 可选段落结构

结果段可按“位置与层段—客观特征—空间或垂向变化”展开。讨论段可按“待解释现象—独立证据—机制与替代解释—适用范围”展开。结构取决于材料，不强迫所有稿件使用同一地层划分。

## 跨域注意事项

借用核磁、岩石物理或 AI 结果时，先确认标定、尺度和外部验证；模型预测的岩相不等于独立地质观察。讨论页岩富集时，将沉积控制与后期成岩、热演化、构造保存及工程因素分别论证。

## 中英术语与使用边界

| 中文 | 英文 | 使用限制 |
|---|---|---|
| 岩相 | lithofacies | 优先表示岩石特征，不直接等同环境 |
| 相组合 | facies association | 需说明空间或垂向联系 |
| 沉积相 | sedimentary facies | 按目标期刊和既有定义保持一致 |
| 沉积环境 | depositional environment | 属解释层面，需证据支撑 |
| 沉积构造 | sedimentary structure | 区分原生与后期变形 |
| 层序 | depositional sequence | 需交代界面及划分依据 |
| 旋回地层学 | cyclostratigraphy | 有旋回不代表已建立天文年代标尺 |
| 古氧化还原条件 | paleoredox conditions | 指标解释需排除干扰 |
| 古生产力 | paleoproductivity | 区分生产、保存和稀释 |
| 物源 | provenance | 区分源区属性与搬运分选效应 |
| 成岩作用 | diagenesis | 不与沉积时环境混写 |
