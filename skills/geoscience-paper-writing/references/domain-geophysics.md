# 地球物理写作指南

本指南为规范性方法提醒，不代表已经从用户的 Zotero 全文中归纳出写作规律。

## 范围与论证链

适用于用户“核磁相关、岩石物理、人工智能”资料组中的测量、物性解释、反演和预测研究。建立“测试条件与输入 → 可复现处理 → 直接观测或模型输出 → 独立验证 → 地质意义”的链条，明确哪些量为实测、反演或经验估算。

## 证据与方法约束

- 核磁报告仪器和关键采集条件，以及流体、饱和状态、温压和样品处理；讨论条件变化对弛豫谱的影响。
- T₂ 到孔径的转换须说明表面弛豫率、流体与润湿性等假设及标定依据；束缚流体划分不得套用未经验证的统一阈值。
- 岩石物理关系交代有效应力、饱和度、频率、方向性、岩性和尺度。岩心、测井和地震观测之间的推广须有尺度转换依据。
- 反演说明正则化、初始假设、非唯一性和误差；拟合优度不能独立证明地质解释正确。
- AI 数据划分对应预期应用场景，优先检查井、地区、时间和重复样本造成的依赖；归一化、特征选择和调参只使用允许的训练信息。
- 比较基线、外部验证、分群表现和不确定性；特征重要性或解释性图件不能直接证明地质因果机制。
- 指标、单位、样本层级及验证范围保持一致；不能把大量相关测点写成同等数量的独立样本。

写作前核对预测目标的获取方法及其误差来源，并检查训练标签是否包含待验证方法本身的估算值。展示效果最好与最差的样本或层段，说明可应用条件；缺少独立验证时，应降低推广结论的强度。

## 可选段落结构

方法段按“测量—处理—模型—验证”展开。结果先报告观测和性能，讨论再解释其物理或地质意义，并说明失效条件；不要让模型名称代替研究问题。

## 跨域注意事项

用地球物理结果讨论沉积相或非常规储层时，注明解释所需的地质先验。若稿件核心是储集机制，应转用非常规油气主线；若核心是核磁标定或反演，则维持本指南为主。

## 中英术语与使用边界

| 中文 | 英文 | 使用限制 |
|---|---|---|
| 岩石物性评价 | petrophysics | 常用于孔渗及测井相关评价，依期刊语境 |
| 岩石物理 | rock physics | 强调物性与弹性等响应关系，勿机械互换 |
| 核磁共振 | nuclear magnetic resonance (NMR) | 区分实验室与井下观测 |
| 横向弛豫时间 | transverse relaxation time (T₂) | 不直接等同孔径 |
| 表面弛豫率 | surface relaxivity | 需说明假设或标定 |
| 束缚流体 | bound fluid | 说明操作性定义和划分方法 |
| 反演 | inversion | 区分直接测量与反演结果 |
| 尺度转换 | upscaling | 说明由何尺度推广至何尺度 |
| 数据泄漏 | data leakage | 检查处理、划分和目标衍生信息 |
| 外部验证 | external validation | 外部性需对应井、地区或时间等边界 |
| 不确定性量化 | uncertainty quantification | 区分数据、参数和模型来源 |
