# 中文科技论文写作

输出中文稿件。引用外文文献时保留发表时的题名和作者信息。

- 采用准确、紧凑的地学科技论文表述，按目标期刊选用结构式或非结构式摘要。
- 区分“观察到/测得”“表明/支持”“可能与……有关”。“显著”需有统计或明确幅度依据；“控制”“证实”“揭示机制”需相应证据，不用修辞替代验证。
- 术语在首处给出全称与缩写，之后保持一致；中文地层、地区名用作者核定形式。地层单位、岩性名称、地质时代与地质年代不要混用。
- 长句按证据关系拆分，明确主语、比较对象、因果条件和范围；避免“对……进行了研究，取得良好效果”的空泛方法复述。
- 数据与单位统一，百分数变化区分相对增幅与百分点，孔隙度和含气量说明分母/基准。引文按照目标期刊处理，不默认固定引文编号格式。
- 先写发现，再用观测或比较支撑。把有实质影响的样品、层位与比较条件写进对应句子。

## 语言风格与句段组织

将用户原有表达习惯作为起点，保留有效术语和作者声音。参考库的措辞是参照，不是必须模仿的标准。优先写清研究对象、条件和动作：把“对于……方面进行了研究”改为明确的主谓宾，删除没有增加证据的“众所周知、具有十分重要的意义”等铺垫。

段落衔接说明实际关系：证据支持、条件限制、比较差异或替代解释；不用反复的“此外、同时、综上所述”掩盖逻辑断层。结果部分使用平行句式描述可比对象，讨论部分准确区分“由……导致”“与……相关”和“可能反映……”。

表达示例。原稿“我们仅作了初步分析，结果可能在一定程度上提示该层段 TOC 与 U/Th 存在正相关”。若材料给出的是该层段样品的正相关，可写成“该层段样品的 TOC 与 U/Th 呈正相关”。若“初步”对应具体的探索性设计或未完成的检验，写明其实际含义。
