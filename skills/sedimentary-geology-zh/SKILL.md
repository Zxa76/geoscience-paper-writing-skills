# 沉积地质-中文

按用户指定目标输出中文论文。保留作者数据、单位、已有结论与不确定性，区分观测、文献证据和推断；缺失数据标为待补。目标稿件语言和参考文献语言是不同选择。跨域论文按主要科学问题选主入口，必要时加载另一领域指南。

## 工作流程

1. 阅读 [共用写作工作流](../geoscience-paper-writing/references/workflow.md)。
2. 阅读 [沉积地质领域指南](../geoscience-paper-writing/references/domain-sedimentary.md) 和 [中文写作规范](../geoscience-paper-writing/references/language-zh.md)。
3. 用户需要使用自己的文献时，阅读 [Zotero使用说明](../geoscience-paper-writing/references/zotero.md)，按需查阅题录和摘要；未经原文核验不得宣称方法与数值已核实。未经要求不修改文献库。
4. 交付实际正文、提纲或修改稿，指出影响当前写作的证据缺口；按用户期刊要求调整，不默认Nature风格。
